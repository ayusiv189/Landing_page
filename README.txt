TRUFIT GITHUB PAGES READY PACKAGE

1. Upload everything in this folder to the root of your TURFIT GitHub repository.
2. Commit to the main branch.
3. In GitHub: Settings -> Pages -> Source -> GitHub Actions.
4. The workflow will deploy index.html automatically.
